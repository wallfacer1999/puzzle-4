# T字拼图小游戏软件 V1.0 用户操作说明书

## 1. 软件简介

T字拼图小游戏软件是一款休闲益智类拼图游戏。玩家需要在规定时间内操作四块不同形状的木块，通过移动、旋转和翻面，将其拼成完整的 T 字形。

软件支持网页端验证，也可以构建为微信小程序，并为抖音小程序适配预留跨端能力。

## 2. 进入游戏

用户打开软件后，页面显示游戏标题、倒计时区域、棋盘区域和拼好的 T 字预览。系统会自动播放三步操作教学，帮助用户理解基本操作方式。

教学包含：

1. 按住木块拖动。
2. 轻点木块翻面。
3. 按住任意角旋转。

教学结束后，页面显示开始面板，用户可以选择开始挑战、静音开始或重看教学。

## 3. 开始挑战

用户点击“开始挑战”后，系统会将四块木块随机打散到棋盘上，并启动倒计时。若用户点击“静音开始”，软件会关闭背景音乐并开始游戏。

游戏限时为 90 秒。最后 20 秒时，倒计时显示会进入紧张状态，背景音乐也会切换为更快的节奏。

## 4. 移动木块

用户可以按住任意木块的有效多边形区域并拖动，将木块移动到目标位置。软件采用多边形命中区域，不以外接矩形作为操作区域，从而减少木块互相遮挡时的误触。

当用户操作某块木块时，该木块会轻微浮起并显示为当前选中状态。松手后，木块回落到棋盘上。

## 5. 翻面木块

用户可以轻点木块进行翻面。翻面会将木块按水平镜像方式变换，模拟真实木块翻到另一面的效果。

为了避免误触，软件只在短时间轻点且没有拖动时触发翻面。长按不动或短距离拖动不会被判定为翻面。

## 6. 旋转木块

用户可以按住木块任意顶点附近并拖动，实现木块旋转。旋转时，软件根据手指或鼠标位置相对于木块中心的角度变化实时更新木块角度。

当用户松手时，如果木块角度距离水平或垂直方向只差几度，系统会自动吸附到 0 度、90 度、180 度或 270 度，帮助用户完成精确摆放。

## 7. 自动判定

软件不需要用户手动点击判定按钮。每次用户完成一次移动、旋转或翻面操作后，系统会自动检查当前拼图结果。

系统会综合判断：

1. 木块之间是否重叠过多。
2. 组合出的形状是否接近 T 字目标区域。
3. 是否有明显超出或空缺。
4. 组合结果是否可以通过小范围平移与目标形状匹配。

如果满足条件，系统会判定成功。

## 8. 成功与失败

若用户在规定时间内拼成 T 字，软件会显示成功弹窗，并播放成功音效。弹窗中提供“重来”和“分享给朋友试试”等操作。

若倒计时结束仍未完成，软件会显示失败弹窗，并播放失败音效。弹窗中提供“重来”和“降低难度”等操作。

成功或失败时，背景音乐会自动暂停。

## 9. 难度说明

软件包含普通模式和简单模式。

普通模式下，棋盘不显示 T 字提示区域，四块木块使用相同木纹风格，玩家需要根据形状关系完成拼图。

简单模式下，棋盘显示 T 字目标区域，四块木块使用不同颜色和纹理辅助识别，适合首次体验或降低难度。

## 10. 音乐控制

棋盘右上角提供音乐按钮。用户可以点击按钮开启或关闭背景音乐。音乐默认关闭，开启后按钮会显示播放状态。游戏成功或失败时，背景音乐自动暂停。

## 11. 重新开始

用户可以在结果弹窗中点击“重来”。重来后，系统会重新显示教学和开始面板，用户可以重新开始挑战。

## 12. 注意事项

1. 在手机端操作时，建议使用单指操作。
2. 轻点翻面与拖动移动是不同操作，长按或滑动不会触发翻面。
3. 若木块被其他木块遮住，可先移动上层木块，或从露出的有效区域拖动目标木块。
4. H5 端用于调试验证，小程序端以实际构建产物为准。
