# T字拼图小游戏软件 V1.0 软件设计说明书

## 1. 软件概述

T字拼图小游戏软件是一款面向移动端和网页端的益智拼图游戏。软件提供四块固定形状木块，玩家需要在限定时间内通过移动、旋转和翻面，将四块木块组合成目标 T 字形。软件使用 uni-app、Vue 3、TypeScript 和 Vite 开发，能够在 H5 浏览器中验证，也能够构建为微信小程序，并为后续适配抖音小程序保留跨端结构。

软件面向休闲益智娱乐场景，重点强调简单直观的交互、跨端一致的视觉表现和可维护的判定逻辑。玩家进入游戏后先观看操作教学，然后点击开始挑战，系统将木块打散并启动倒计时。玩家每次操作结束后，系统自动检查当前拼图状态，若满足目标条件则显示成功弹窗；若倒计时结束仍未完成，则显示失败弹窗。

## 2. 设计目标

1. 支持 H5、微信小程序和抖音小程序目标平台。
2. 使用统一业务代码实现跨端一致玩法。
3. 支持四块固定多边形木块的移动、旋转和翻面。
4. 支持开局教学、打散动画、倒计时、背景音乐和结果弹窗。
5. 支持游戏结果自动判定，减少玩家手动点击判定步骤。
6. 支持难度切换，简单版显示目标区域和颜色提示，普通版隐藏目标提示并使用木纹。
7. 保持规则层、状态层和组件层解耦，便于后续增加关卡和新平台。

## 3. 总体架构

软件采用分层架构：

1. 页面层
   - 文件：`src/pages/game/index.vue`
   - 负责组合棋盘、工具栏、开始面板、教学提示和结果弹窗。
   - 管理页面阶段，如教学、预览、打散和游戏进行中。

2. 组件层
   - `PuzzleBoard.vue`：负责棋盘、目标轮廓、木块列表、音乐按钮和命中检测。
   - `PuzzlePiece.vue`：负责单个木块的多边形渲染、翻面动画、旋转点和选中效果。
   - `GameToolbar.vue`：负责倒计时展示。
   - `ResultModal.vue`：负责成功、失败和重来交互。

3. 状态层
   - `usePuzzleGame.ts`：负责游戏状态、计时器、木块数据、重开、判定、成功失败流程。
   - `usePieceGesture.ts`：负责触摸点、拖拽、旋转和轻点判定。

4. 规则层
   - `rules.ts`：负责角度归一化、多边形面积采样、重叠率、覆盖率、超出率、空缺率和结果判定。
   - `randomize.ts`：负责随机打散木块并生成初始局面。

5. 配置层
   - `levels.ts`：定义关卡、木块几何点、目标布局、倒计时、难度和容差。
   - `types.ts`：定义软件使用的数据结构。

## 4. 核心模块设计

### 4.1 页面控制模块

页面控制模块负责游戏主流程。进入页面后，系统展示拼好的 T 字预览并播放三步教学动画。教学结束后显示开始面板，玩家可以选择开始挑战、静音开始或重看教学。点击开始后，页面进入打散阶段，木块随机散落到棋盘上，并在动画结束后进入游戏阶段。

页面模块还负责背景音乐开关、成功失败音效播放、调试信息显示控制以及分享提示。为了避免平台差异，页面不直接使用浏览器专用 DOM 操作，而是通过 uni-app 接口和 Vue 状态完成跨端控制。

### 4.2 棋盘模块

棋盘模块使用逻辑坐标系描述游戏区域，默认棋盘宽度为 750，高度为 1000。不同终端渲染时，根据屏幕尺寸计算缩放比例，将逻辑坐标转换为屏幕坐标。这样可以保证同一份木块和判定数据在 H5 与小程序中保持一致。

棋盘模块负责命中检测。系统先检测触摸点是否落在木块顶点附近，如果命中顶点，则进入旋转模式；否则检测触摸点是否落在木块多边形区域内，如果命中，则进入拖拽模式。该设计避免使用外接矩形作为命中区域，减少木块之间互相遮挡时的误操作。

### 4.3 木块渲染模块

木块模块以多边形顶点数组作为基础数据，通过 CSS clip-path 显示真实形状。普通模式下木块使用浅色木纹贴图，简单模式下使用不同颜色和纹理辅助玩家识别。木块支持如下交互：

1. 轻点翻面：短时间点击且没有移动时触发镜像翻面。
2. 按住拖动：在木块多边形区域内按住并移动时，更新木块中心坐标。
3. 顶点旋转：按住任意顶点附近区域并拖动时，更新木块旋转角度。
4. 操作选中：玩家操作某个木块时，木块轻微浮起并置于上层。

木块翻面采用水平镜像逻辑，视觉上模拟真实木块翻到另一面。

### 4.4 手势模块

手势模块将用户操作区分为轻点、拖拽和旋转。轻点需要满足短时间内完成、没有移动事件、起点和终点距离小于阈值。长按不动不视为轻点，避免玩家按住木块准备拖动时误触翻面。

拖拽手势根据当前点和上一点之间的差值计算位移，并按棋盘缩放比例换算回逻辑坐标。旋转手势根据触摸点和木块中心之间的夹角变化计算角度增量。手势结束时，系统会触发一次自动判定，并对接近水平或垂直的角度进行吸附。

### 4.5 游戏状态模块

游戏状态模块维护木块列表、当前状态、倒计时、已用时间、弹窗状态和当前活动木块。主要方法包括：

1. `showSolvedPreview`：显示拼好状态。
2. `startGame`：随机打散木块并准备开始。
3. `beginCountdown`：启动倒计时。
4. `movePiece`：移动木块。
5. `rotatePiece`：旋转木块。
6. `flipPiece`：翻面木块。
7. `snapPieceRotation`：角度吸附。
8. `checkSolved`：检查是否拼对。
9. `failByTimeout`：倒计时结束时失败处理。
10. `switchLevel`：切换难度。

### 4.6 判定规则模块

判定规则不再要求玩家拼出的 T 字必须与预设坐标完全重合，而是根据组合形状进行判断。系统先检测木块之间的重叠比例，再计算木块组合区域与目标 T 字区域之间的匹配程度。为了兼容玩家将 T 字摆在棋盘不同位置的情况，规则模块会在一定范围内尝试平移组合结果，寻找与目标区域的最佳重合。

判定指标包括：

1. 木块遮挡率：木块之间互相重叠的面积比例。
2. 整体覆盖率：组合结果覆盖目标区域的比例。
3. 超出率：组合结果超出目标区域的比例。
4. 空缺率：目标区域未被组合结果覆盖的比例。
5. 整体偏差：组合结果与目标区域的整体差异。

普通模式下不显示目标轮廓，但判定仍使用同一套目标几何数据。

## 5. 数据结构设计

### 5.1 木块数据

木块数据包括编号、中心坐标、宽高、旋转角度、是否翻面、颜色、纹理地址、顶点数组、操作中心和层级。顶点数组用于渲染和命中检测，中心坐标和旋转角度用于实时变换。

### 5.2 关卡数据

关卡数据包括关卡编号、名称、难度、棋盘尺寸、限时、木块模板、目标布局和判定容差。当前版本包含普通模式和简单模式，后续可以通过增加关卡配置扩展更多拼图。

### 5.3 判定容差

判定容差包括位置容差、角度容差、遮挡率阈值、超出率阈值、空缺率阈值、整体偏差阈值、面积采样步长和平移搜索半径。该设计允许不同难度使用不同判定标准。

## 6. 运行流程

1. 用户打开软件。
2. 系统加载默认关卡并展示已完成的 T 字预览。
3. 系统播放移动、翻面、旋转三步教学动画。
4. 用户点击开始挑战或静音开始。
5. 系统将木块随机打散到棋盘上。
6. 系统启动 90 秒倒计时。
7. 用户拖动、旋转或翻面木块。
8. 每次操作结束后系统自动进行结果判定。
9. 若拼图成功，系统暂停背景音乐并播放成功音效，显示成功弹窗。
10. 若倒计时结束仍未成功，系统暂停背景音乐并播放失败音效，显示失败弹窗。
11. 用户可选择重来、降低难度或分享给朋友。

## 7. 跨端适配设计

软件基于 uni-app 构建，使用 Vue 3 组件和 uni-app 运行时能力实现跨端。H5 端用于快速验证和调试，小程序端通过构建命令生成微信小程序产物。后续适配抖音小程序时，可以保留核心组件、状态和规则逻辑，仅对平台专用音频、分享和配置进行条件适配。

为了提高跨端稳定性，软件避免依赖浏览器专用的 `window`、`document` 和 Pointer API。棋盘坐标通过逻辑坐标和缩放比例控制，触摸事件使用 uni-app 可兼容的事件结构。

## 8. 音频与视觉设计

软件包含背景音乐、倒计时加速音乐、成功音效和失败音效。背景音乐默认关闭，玩家可以在棋盘右上角打开。成功或失败时系统自动暂停背景音乐并播放对应音效。

视觉上，软件采用漫画风格背景、网格棋盘、浅色木纹木块、圆角弹窗和按钮反馈。木块被操作时有轻微浮起效果，帮助用户识别当前操作对象。

## 9. 测试说明

软件包含逻辑测试脚本，用于验证角度归一化、角度距离、拼图判定和随机打散边界。开发阶段还通过 H5 页面进行手动验证，检查倒计时、教学、拖拽、旋转、翻面、自动判定、成功失败弹窗和移动端布局。

常用测试命令包括：

```bash
npm run test:logic
npm run type-check
npm run build:h5
npm run build:mp-weixin
```

## 10. 版本说明

当前版本为 V1.0，实现单关卡四块 T 字拼图玩法，支持普通模式和简单模式。V1.0 已具备基础游戏流程、跨端构建能力、自动判定、操作教学、音频反馈和结果弹窗。
