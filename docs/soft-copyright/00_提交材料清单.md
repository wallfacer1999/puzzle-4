# T字拼图小游戏软件 V1.0 软件著作权登记材料清单

生成日期：2026-06-02

## 一、已生成材料

1. `01_申请信息采集表.md`
   - 用于填写中国版权保护中心申请表或提交给代理机构。
   - 申请人、证件号、地址、完成日期等字段需要由权利人确认。

2. `02_软件设计说明书.md`
   - 作为软件文档鉴别材料使用。
   - 内容包含软件概述、运行环境、架构设计、模块说明、核心流程、数据结构、跨端适配、安全与测试说明。

3. `03_源程序鉴别材料_前后各30页.txt`
   - 由项目源代码自动汇总生成。
   - 代码总量超过 3000 行，按常见软著口径截取前 1500 行和后 1500 行，每页 50 行，共 60 页。

4. `04_用户操作说明书.md`
   - 可作为操作手册/用户手册材料使用。
   - 内容覆盖 H5、微信小程序和抖音小程序目标运行场景。

5. `05_原创及权属声明模板.md`
   - 用于申请人内部留存或代理机构要求时补充。
   - 签署前应由权利人核对事实。

## 二、仍需人工补充或确认

1. 申请人信息
   - 自然人：姓名、身份证号码、联系地址、手机号、邮箱。
   - 企业：公司全称、统一社会信用代码、注册地址、联系人信息。

2. 权利取得方式
   - 通常选择“原始取得”。
   - 如存在委托开发、合作开发、职务开发，需要补合同、协议或任务书。

3. 开发完成日期与首次发表日期
   - 如未上线，可填写“未发表”。
   - 日期要与实际开发、发布记录一致。

4. 软件名称
   - 建议：`T字拼图小游戏软件`
   - 版本号：`V1.0`
   - 简称可填：`T字拼图`

5. 身份证明材料
   - 自然人身份证正反面复印件。
   - 企业营业执照复印件并按要求盖章。

## 三、提交前格式建议

1. 源程序材料
   - A4 单面打印。
   - 页眉建议标注：`T字拼图小游戏软件 V1.0`
   - 右上角标注页码：`第 X 页 / 共 60 页`
   - 每页约 50 行代码。

2. 文档材料
   - 可将 `02_软件设计说明书.md` 或 `04_用户操作说明书.md` 转为 Word/PDF。
   - 页眉建议标注：`T字拼图小游戏软件 V1.0`
   - 右上角标注页码。
   - 文档不足 60 页时通常提交全部文档。

3. 申请表
   - 以中国版权保护中心登记系统最终生成的表格为准。
   - 不建议手写或自行仿制最终申请表。
